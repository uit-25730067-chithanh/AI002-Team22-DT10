## Compile Command

```bash
cd frontend
npm run compile
```

## Publish Command

```bash
cd frontend
PATH=$HOME/.nvm/versions/node/v22.12.0/bin:$PATH wrangler pages deploy <vite-output-folder> --project-name ai002-coffee-frontend --commit-dirty=true
```

Replace `<vite-output-folder>` with the folder generated by Vite production compile.

## Environment Variables

Frontend uses Vite variables at compile time:

- `VITE_API_BASE_URL`: public backend API base URL.
- `VITE_AI002_API_KEY`: demo API key sent as `X-API-Key`.

If these are not configured before compile/publish, the frontend falls back to `http://127.0.0.1:8000`, which only works on local machines.

## Rollback

```bash
wrangler pages deployment list --project-name ai002-coffee-frontend
```

Use Cloudflare Dashboard > Pages > `ai002-coffee-frontend` > Deployments to promote or rollback a deployment.
